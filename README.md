
# Seasonal Progress Tracker (Next.js) - Dark Theme

This is the improved dark-themed version. Changes:
- Always dark theme
- Vertical stacked day cards
- Styled season toggles (pill buttons) with localStorage persistence
- Progress bar for each entry
- Styled buttons for + / - / Set total / Delete
- Data persisted to MongoDB (or fallback JSON)

Run with `npm install` and `npm run dev`.
